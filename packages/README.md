# Curated Packages

The Packages maintained in this repository are listed below. Each Package links
to its setup and usage documentation. See the
[curated Packages reference](https://submilli.ai/docs/reference/curated-packages)
for credentials, required hosts, and installation commands.

Missing an integration? [Request a curated Package](https://github.com/submilli/submilli-runtime/issues/new?template=curated-package.yml).

| Package | For |
| --- | --- |
| [`@submilli/brave-search`](brave-search/readme.md) | Brave web search and extracted passages with source URLs. |
| [`@submilli/exa`](exa/readme.md) | Exa web search with highlights and content extraction from known URLs. |
| [`@submilli/firecrawl`](firecrawl/readme.md) | Web search, page scraping, site URL discovery, and batch scrape and crawl jobs. |
| [`@submilli/github`](github/readme.md) | GitHub repositories, files, commits, branches, issues, pull requests, teams, releases, and search. |
| [`@submilli/gmail`](gmail/readme.md) | Gmail search, threads, messages, drafts, labels, attachments, and sending mail. |
| [`@submilli/google-calendar`](google-calendar/readme.md) | Google Calendar calendars, events, agendas, free/busy queries, and free-time searches. |
| [`@submilli/google-drive`](google-drive/readme.md) | Google Drive files, folders, Shared Drives, uploads, downloads, and sharing. |
| [`@submilli/jina`](jina/readme.md) | Jina Reader and Search for web pages and search results as Markdown or structured data. |
| [`@submilli/linear`](linear/readme.md) | Linear issues, comments, teams, projects, users, and agent sessions. |
| [`@submilli/notion`](notion/readme.md) | Notion search, pages, Markdown, databases, data sources, views, comments, blocks, and file uploads. |
| [`@submilli/sentry`](sentry/readme.md) | Sentry Cloud organizations, projects, issues, events, and issue triage. |
| [`@submilli/slack-bot`](slack-bot/readme.md) | Slack messages, conversations, users, and reactions as the app's bot. |
| [`@submilli/slack-user`](slack-user/readme.md) | Slack search, messages, channels, users, files, and reactions as the authenticated user. |
| [`@submilli/typesafe`](typesafe/readme.md) | TypeSafe's Jev model for yes/no, choice, and scoring judgments with typed answers and probabilities. |
